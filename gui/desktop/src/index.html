How It Works

1
Layer-wise Loading

Instead of loading the entire model into GPU memory, AirLLM loads one transformer layer at a time.

2
Compute & Offload

Each layer runs inference on GPU, then its weights are immediately moved back to CPU/disk — freeing VRAM.

3
Compression

Optional quantization (int4/int8) further reduces the memory footprint by up to 8×.
